Architecture & Engineering Specification

Two-Service Architecture with Government Integration Adapters

Engineered for solo developer velocity, sub-second queue responsiveness, and resilient state-level scale.

1. Farmer & Staff Channel Layer (Multi-Device Delivery) Omnichannel Access
React 18 + Vite PWA Staff Operator Dashboard USSD Gateway Simulator Web Speech IVR Engine Workbox Offline ServiceWorker
2. Core Transaction Service (Spring Boot 3.3 • Java 21 LTS) ACID & Business Logic
Spring Security (JWT/RBAC) Capacity Booking API Token Lifecycle Engine Procurement & QC Module PFMS DBT Sync DPDP Consent & Audit Logs
3. Real-Time Service (Node.js 22 LTS • Socket.io) Sub-Second Queue Push
Socket.io 4.7 (Mandi Room Broadcasts) Redis Pub/Sub Adapter USSD Session State Machine Zod Event Schemas
4. High-Performance Data Layer Persistence & In-Memory Speed
PostgreSQL 16 (JSONB, pg_audit, Row-Level Security) Redis 7.2 (Queue Sorted Sets, Rate Limits, Token Cache)
5. Government Integration Adapter Layer (Pluggable SPI) Production-Ready Mocks
AgriStack Farmer ID UIDAI Aadhaar e-KYC PFMS / DBT Payment Tracker e-Paddy / e-Kharid Adapters

⚡ Real-Time Queue Methodology

  • Dynamic ETA: Calculated using active processing counters & moving average service rate.
  • Event Propagation: Staff action (e.g. Weighing) commits to DB → pushes to Redis Pub/Sub in <50ms.
  • Offline Resilience: PWA stores latest verified token in IndexedDB/LocalStorage during network drops.

🛡️ Solo Developer Velocity

  • Two Deployable Units: Spring Boot Core + Node.js Real-time allows rapid 1-week build & testing.
  • Predictable Mocks: Deterministic government mock adapters isolate external API dependency risks.
🔒 SECURITY & COMPLIANCE: DPDP Act 2023 Aligned • Consent Capture • Token Bucket Rate Limiting (Bucket4j) • RBAC • TLS 1.3 / AES-256 • Immutable Audit Logs

Empirical Grounding, Standards & Verification

Research Foundation and Validation Plan

Translating field observations into resilient architecture aligned with national digital public infrastructure.

Observation 1: Farmers battle fragmented state portals with isolated user credentials.
Design Response: AgriStack Farmer ID abstraction with pluggable state adapter pattern.
Observation 2: 40%+ of rural farming households rely on basic 2G feature phones.
Design Response: Zero-smartphone penalty: full parity via USSD state machine & IVR voice.
Observation 3: Sensitive land records & bank DBT accounts vulnerable to misuse.
Design Response: DPDP 2023 compliance: explicit purpose consent, RBAC & audit trails.
Observation 4: Production govt APIs require accredited agency credentials.
Design Response: Production-grade mock adapters emulating realistic latency & error quotas.
